# Active Inference Institute

**Act. Infer. Serve.**

A volunteer-led, participatory open science 501(c)(3) nonprofit supporting education, research, training, and applications of Active Inference and the Free Energy Principle.

[Website](https://activeinference.institute/) · [YouTube](https://www.youtube.com/@ActiveInference/) · [Discord](https://discord.activeinference.institute) · [Newsletter](https://newsletter.activeinference.institute/) · [Knowledge base](https://obsidian.activeinference.institute) · [Get involved](https://activeinference.institute/get-involved/) · [Donate](https://donate.activeinference.institute/)
