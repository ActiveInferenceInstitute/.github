# Publication boundary and limits

Raw fleet reports may contain repositories of different visibility. The public ledger builder admits named entries for the public scope and aggregates the private results. A separate boundary command then checks the serialized ledger against the same scope, including case-insensitive identity and repository URL checks. The owner retains the scope and raw report outside the public checkout [@aii-ledger-boundary].

Deterministic output makes independent comparison possible. It does not establish that the caller supplied the intended checkout, that API measurements were available, or that a fleet ledger check was run against the authoritative scope. The reusable workflow evaluates the declared repository gate on adoption; the owner-operated boundary remains the evidence for publishing a fleet ledger.
